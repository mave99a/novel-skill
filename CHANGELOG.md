# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-01-07

### Added
- Initial release of Novel Creator skill
- 5-phase workflow: Story Setup, Interactive RPG, Writing Plan, Chapter Writing, EPUB Generation
- Interactive RPG-style story building with `AskUserQuestion` tool
- Professional EPUB generation with Chinese typography support
- Character persona templates for Palace, Modern, and Fantasy settings
- Poetry and lyrics pairing database for Chinese novels
- Support for multiple genres: 穿越 (time-travel), Fantasy, Romance, Mystery
- Customizable writing styles (琼瑶, 张爱玲, 金庸)
- Sample novels demonstrating full workflow output

### Resources
- `create_epub.py` - EPUB generator script with cover page and TOC
- `personas.md` - 40+ character templates
- `poetry_pairs.md` - 30+ poetry/lyrics pairings by theme
